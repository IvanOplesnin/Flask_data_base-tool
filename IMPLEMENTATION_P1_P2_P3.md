# Внедрение P1–P3

## Что добавлено

- Единая русская навигация: расчёты, справочники, эксперименты, импорт и администрирование.
- Единый реестр поддерживаемых операций: точение, фрезерование, резьбонарезание.
- Безопасное переключение вида обработки без переноса старых ID материала, инструмента и покрытия.
- Проверяемые расчёты режимов по референсным калькуляторам INNER:
  - точение — скорость, подача по шероховатости, обороты, модель Kienzle, сила,
    мощность, момент, число проходов и оценка времени;
  - фрезерование — обороты, подача, поправка RCTF, объём съёма, модель Kienzle,
    мощность и момент;
  - резьбонарезание — обороты и подача по шагу резьбы.
- API расчёта: `POST /api/calculate/{turning|milling|threading}`.
- Связка расчёта со справочниками: `GET /api/cutting-reference` подбирает
  параметры по тройке материал–инструмент–покрытие, а API расчёта использует их
  как значения по умолчанию.
- Импорт русских и технических CSV-заголовков.
- Workflow импорта: писатель загружает и подтверждает техническую проверку, администратор публикует или отклоняет данные, читатель видит только опубликованные эксперименты.
- Экспериментальные графики строятся только по фактическим измерениям износа.
- Отдельные демонстрационные кривые доступны по адресу `/experiments/reference` и явно помечены как демо.
- Единообразные кнопки добавления для фрез, пластин и метчиков.
- Для пластин добавлены поля марки сплава, геометрии и углов.
- Будущие операции (сверление, шлифование и другие) отображаются как «в разработке» и не выдают пустой калькулятор.

Для новой установки или другого окружения:

```bash
flask db upgrade
```

При выборе материала, инструмента и покрытия форма запрашивает справочную
связку и подставляет `Vc`, `fz`, `kc1`, `mc` и угол инструмента. Ручной ввод
помечается как переопределение и не заменяется следующей загрузкой. Для
существующих рекомендаций базовые `Vc` и `fz` берутся из
`RecommendationParameter`; новые Kienzle-поля хранятся в `Coefficient`.

## Формулы режимов резания

Реализация находится в `my_app/services/cutting_calculations.py`. Все длины и
подачи передаются в мм, скорость резания — в м/мин, обороты — в об/мин,
мощность — в кВт. Коэффициенты материала `kc1` и `mc` не зашиваются в код:
их нужно брать из проверенного справочника материала/инструмента.

### Точение

- при заданных коэффициентах скорости: `Vc = Vc_base × Ktool × Koperation ×
  Kcoolant × Kstiffness`;
- подача по шероховатости: `f = sqrt(Ra × 32 × r / (1000 × 1.3))`;
- обороты: `n = (Vc × 1000) / (π × D)`;
- толщина среза: `hm = f × sin(KAPR)`;
- удельная сила по Kienzle: `kc = kc1 × hm^(-mc) × (1 − γ/100)`;
- сила и мощность: `Fc = kc × ap × f`, `Pc = Fc × Vc / 60000`;
- момент: `Mc = Pc × 9549 / n`;
- число проходов и время: `ceil(припуск / ap)`, затем `L / (f × n)` на
  проход.

### Фрезерование

- обороты: `n = (Vc × 1000) / (π × D)`;
- подача на зуб: `fz = fz_base × sqrt(D/10) × Koperation` (либо явно
  введённое `fz`);
- минутная подача: `F = fz × z × n`;
- поправка СОЖ по методике: эмульсия `1,00`, MQL/масло `0,90`, обдув
  `0,85`, сухая обработка `0,80` (явный коэффициент может переопределить
  значение);
- поправка радиального утонения при `ae < D/2`: `RCTF = 1 / sqrt(1 −
  (1 − 2×ae/D)^2)`;
- объём съёма: `Q = ap × ae × F / 1000` в см³/мин;
- при наличии `kc1`, `mc`, `hm`: `Pc = Q × kc / 60000`, `Mc = Pc × 9549 / n`.
  Если `hm` не задана, сервис использует `fz` как явно отмеченное приближение.

### Резьбонарезание

- обороты рассчитываются общей формулой `n = (Vc × 1000) / (π × D)`;
- подача на оборот равна шагу резьбы: `f = pitch`, поэтому `F = pitch × n`.

Источник формул: [калькулятор точения INNER](https://inner.su/services/kalkulyator-rezhimov-rezaniya-dlya-chpu-skorost-podacha-oboroty-dlya-tokarnoy-obrabotki/)
и [калькулятор фрезерования INNER](https://inner.su/services/kalkulyator-rezhimov-rezaniya-chpu-frezerovaniya-onlayn-raschet-podach-oborotov/).
Результат является предварительной технологической оценкой: перед запуском
на станке необходимо сверить коэффициенты, инструмент, СОЖ, жёсткость и
ограничения конкретного оборудования.
